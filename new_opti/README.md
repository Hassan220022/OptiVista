# AR Eyewear App

## Overview
This monorepo contains the source code for the AR Eyewear App, featuring a Flutter frontend and a FastAPI backend, with Supabase as the source of truth for Auth and Database.

## Structure
- `apps/frontend`: Flutter application.
- `apps/backend`: FastAPI backend application.
- `supabase`: Supabase configuration, migrations, and policies.
- `infra`: Infrastructure configuration (Docker, Nginx).
- `docs`: Documentation.

See `docs/` for detailed instructions.
